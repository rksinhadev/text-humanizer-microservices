# Screenshots Guide & UI Walkthrough

This folder contains references and instructions for visual demonstration artifacts required for submission and the lab examination viva.

### Captured / Suggested Screenshots:
1. **`01_landing_dashboard.png`**:
   - The primary user interface of the Text Humanizer at `http://127.0.0.1:5000`.
   - Demonstrates the text input editor, word counters, and humanize trigger buttons.

2. **`02_user_auth_modal.png`**:
   - The user authentication pop-up modal showing registration and login state.
   - Highlights token storage in client local storage.

3. **`03_ai_humanization_output.png`**:
   - Real-time demonstration showing the original AI-detected text on the left and the transformed, humanized output on the right.
   - Shows the Naturalness Score and fluency indicators.

4. **`04_history_audit_logs.png`**:
   - The persistent history table showing past submissions, timestamps, and delete controls.

5. **`05_microservices_terminal.png`**:
   - Terminal view showing all microservices (`gateway:5000`, `auth:5001`, `ai:5003`, `history:5004`) running simultaneously via `run_all.py` or `docker compose`.
